# Security Policy

## Reporting a Vulnerability
- Email: security@firecomm.local
- Include: steps to reproduce, affected version/commit, impact, and any logs.

## Scope
- Backend Socket.IO/Express services
- Frontend client auth/session handling
- Network discovery and dispatch broadcast features

## Response
- We aim to acknowledge within 2 business days.
- Patches or mitigations will be prioritized and documented in `CHANGELOG.md`.

## Safe Harbor
Good-faith security research that respects user data and availability is welcomed. Avoid exploiting issues beyond proof-of-concept and do not access unrelated data.
