# Configuration

## Backend
- `PORT` (default 3001): Socket/HTTP server port.

## Frontend
- Connection bar allows entering backend IP:port at runtime.
- Local storage keys: `firecomm-name`, `firecomm-station`, `firecomm-server`.

## Stations
Default stations: Station 1, Station 2, Station 3, Dispatch, Command.

## Audio
Browser must allow audio for emergency/priority tones.
