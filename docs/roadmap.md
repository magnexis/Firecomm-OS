# Roadmap

## Phase 1 (Done)
- Core chat, stations, presence
- Emergency priority messaging

## Phase 2 (Done)
- Incident management + timelines
- Map with station/incident markers
- Dispatch alerts and unit status

## Phase 3 (Done)
- Full documentation suite
- Settings/logging endpoints
- JWT auth + RBAC, message encryption

## Phase 4+ (In progress)
- Hardware GPS ingestion (mobile + device tokens)
- Drone telemetry/command bridge
- Device security layer, offline buffering

## Future
- Persistent storage (DB) for incidents/logs
- Video ingest for drone feeds
- Analytics dashboard and SLA alerts
- Admin panel with RBAC management UI
