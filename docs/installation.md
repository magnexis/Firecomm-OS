# Installation

## Prerequisites
- Node.js 18+
- npm 9+
- LAN access between clients and server

## Steps
1. Clone repository: `git clone <repo>`
2. Install backend deps: `cd backend && npm install`
3. Install frontend deps: `cd ../frontend && npm install`
4. (Optional) Install Tauri prerequisites for desktop builds.

## Verification
- Run `npm run dev` in backend and confirm server prints LAN IPs.
- Run `npm run dev` in frontend and open the UI.
